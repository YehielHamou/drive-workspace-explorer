Privacy Policy — Drive Workspace Explorer

Zero-Server Architecture: Drive Workspace Explorer operates 100% locally inside your web browser. We do not own, operate, or transmit your data to any external or third-party servers.

1. Data Accessed

When you sign in with Google, the extension requests access to the Google Drive API (https://www.googleapis.com/auth/drive) solely to:

  • Display your Google Drive folder and file hierarchy inside the Chrome Side Panel.
  • Perform file management actions explicitly initiated by you (create folder, rename, move, star, trash/restore, and drag-and-drop file upload).
  • Sync the side panel tree with your currently active Google Drive browser tab when you click the Sync button.

2. Data Storage & Retention

  • No External Databases: No file names, file contents, metadata, or personal identifiers are ever collected, logged, or stored outside your device.
  • Local Browser Storage Only: Expanded folder IDs and UI preferences are stored locally in your browser's localStorage / chrome.storage.local and can be cleared at any time by signing out or uninstalling the extension.

3. Google API Services User Data Policy (Limited Use Compliance)

Drive Workspace Explorer's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Sharing & Third Parties

We do not sell, rent, share, or transfer user data to any third parties, advertising networks, analytics providers, or AI models.

5. Data Protection & Security Mechanisms

We implement strict technical security procedures and encryption standards to protect the confidentiality, integrity, and security of sensitive Google user data:

  • Encryption in Transit (HTTPS / TLS 1.2+): All communication and data transfers between your local Chrome browser and Google Drive API endpoints (https://www.googleapis.com) are strictly encrypted in transit using industry-standard HTTPS / TLS 1.2+ cryptographic protocols.
  • Isolated Browser Sandbox Protection: All data processing occurs exclusively in volatile memory within Google Chrome's isolated extension execution sandbox (Manifest V3), preventing unauthorized access by web pages or other extensions.
  • Secure OAuth 2.0 Token Management: Authentication is handled directly by Google Chrome's native chrome.identity API. Drive Workspace Explorer never accesses, logs, or stores your Google Account password, and OAuth access tokens remain protected within the browser's secure credential environment.
  • Zero External Exposure: Because we operate zero external servers or databases, your sensitive Drive data is never exposed to third-party server breaches, cloud storage leaks, or external network interception.

6. Data Deletion & Access Revocation

  • Local Data Deletion: Users can immediately delete all locally cached UI preferences and folder state at any time by signing out within the extension or uninstalling Drive Workspace Explorer from Chrome.
  • Revoking Google Account Access: Users can revoke the extension's OAuth permissions at any time via their Google Account Security Permissions page.
