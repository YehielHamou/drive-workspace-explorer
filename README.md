# Drive Workspace Explorer 🌳

[![Privacy: 100% Client-Side](https://img.shields.io/badge/Privacy-100%25%20Client--Side-34A853?logo=google)](https://yehielhamou.github.io/drive-workspace-explorer/privacy-policy.html)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-FBBC04?logo=googlechrome&logoColor=white)](#)

Fast, minimalist Google Material 3 folder tree for Google Drive™ inside Chrome's native Side Panel.

## ✨ Key Features
- **Instant Hierarchical Tree**: Browse deeply nested folders with lazy loading and 0ms cached re-expansion.
- **Desktop Drag & Drop**: Drop files from Finder/Explorer directly onto any folder in the tree with live progress.
- **Zero-Server Architecture**: 100% direct client-to-Google OAuth 2.0 communication. No external proxy servers.
- **Multi-Account Switcher**: Seamlessly switch between different Google Drive accounts.
- **Deep Drive Search**: Search files across your entire Drive without leaving your active tab.
